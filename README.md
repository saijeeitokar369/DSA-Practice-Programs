# DSA Practice 🚀

This repository contains my **Data Structures and Algorithms (DSA) practice** programs and problem-solving exercises.

I am using this repository to build a strong foundation in **DSA, logical thinking, problem-solving, and algorithmic programming**.

## 📚 Topics Covered

### 🔹 Arrays

The `array.cpp` and `array1.cpp` to `array4.cpp` files contain practice problems based on **Arrays**.

Topics include:

- Array basics
- Array traversal
- Array operations
- Searching and manipulation
- Problem-solving using arrays

### 🔹 Pattern Printing

The `program1.cpp` to `program7.cpp` files contain **pattern-printing problems**.

These programs help strengthen:

- Loops
- Nested loops
- Logical thinking
- Pattern formation
- Problem-solving skills
